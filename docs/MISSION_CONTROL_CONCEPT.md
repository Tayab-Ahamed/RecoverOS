# RecoverOS Mission Control

The next RecoverOS interface is a **Recovery Mission Control**, not a dashboard. The merchant is looking at a finite recovery window: money is either drifting, being recovered, held for human judgment, or safely left alone.

## The core idea

The centre of the product is a **Revenue River**: a horizontally flowing event canvas that shows the same case moving from signal to diagnosis, proposal, authorization, provider action, and verified capture. The river is the primary navigation surface. The table becomes a secondary ledger for audit and search, not the hero.

## The signature interaction

When the operator clicks a signal, the selected case becomes a **Focus Capsule** on the right. The capsule shows the customer-safe reason, the next move, an expected recovery amount, and an explicit “why not the obvious action?” comparison. The operator can then open the full audit drawer.

A live **Decision Theatre** makes the control plane legible: the agent's thought is shown as evidence, not free-form magic; the policy gate is shown as a hard checkpoint; and payment proof is shown as the only route to verified money.

## Visual identity

The visual language is a dark graphite control room with a narrow electric-blue horizon line, mint for verified money, amber for human judgment, coral for terminal risk, and white for operator actions. The main canvas has a subtle film-grain and scanline texture, but no decorative illustrations. Motion is used only for the active recovery window and event pulse.

## The five-minute story

Start with the sentence: “There is Rs 106,100 drifting in this batch. RecoverOS has already verified Rs 63,756, and it knows exactly why it stopped on the rest.” Select a recovered case to show the river closing at payment proof. Select an escalated case to show the agent choosing restraint over another customer contact. Select an ineligible opt-out case to show a silent stop. Finish in Proof Lab with the adaptive strategy outperforming the fixed baseline at zero governed violations.
